# Текст для защиты

Данные продаж заданы прямо в коде как константа `CSV_DATA`. CSV-таблица имеет четыре колонки: `date`, `item`, `quantity`, `price`.

Функция `parse_csv` принимает CSV в виде строки и возвращает список словарей. Ключи словарей — названия колонок, а значения — строки.

Функция `compute_revenue` вычисляет общую выручку: для каждой строки умножает `quantity` на `price` и складывает результаты.

Функция `top_item` возвращает строку с максимальной выручкой. Если данных нет, она возвращает `None`.

Эти функции чистые, потому что они не читают файлы, не запрашивают ввод, не обращаются к сети и не выводят данные на экран. Вся информация передаётся им через аргументы. Функции не изменяют эти аргументы. При одинаковых аргументах они всегда возвращают одинаковый результат.

Константа `ROWS` содержит результат `parse_csv(CSV_DATA)`, `TOTAL_REVENUE` содержит общую выручку `137.5`, а `TOP_ITEM` содержит данные о товаре «Альбом». Ни одно из этих значений не читается извне.

Если CSV-строка пуста, `parse_csv` вернёт пустой список. Для пустого списка `compute_revenue` вернёт `0`, а `top_item` — `None`.

`parse_csv` принимает значения типа `str` и возвращает `list[dict]`. `compute_revenue` принимает `list[dict]` и возвращает `float`. `top_item` принимает `list[dict]` и возвращает словарь или `None`.
